## Проекты

### Проект 1. Тестирование веб-приложения (учебный проект)
- **Цель:** проверить основные сценарии регистрации и авторизации.
- **Что делал:** составил чек-лист, выполнил позитивные и негативные проверки, нашёл и оформил 5 баг-репортов.
- **Инструменты:** браузер, DevTools, скриншоты.
- **Вывод:** научился описывать шаги и данные для воспроизведения так, чтобы разработчик мог быстро локализовать проблему.

### Проект 2. Тестирование REST API в Postman
- **Цель:** протестировать эндпоинты для получения списка пользователей и создания нового пользователя.
- **Что делал:** создал коллекцию запросов, настроил переменные окружения, проверил коды ответов и валидность JSON.
- **Инструменты:** Postman (коллекции, экспорт), базовые знания HTTP.
- **Вывод:** понял, как связывать запросы в сценарии и проверять соответствие ответа спецификации.

### Проект 3. Тестирование мобильного приложения (Android/iOS)
- **Цель:** проверить базовый сценарий покупки/оформления заказа.
- **Что делал:** проверил сценарии при наличии/отсутствии интернета, проверил корректность отображения на разных экранах.
- **Инструменты:** iPhone 12, Android-устройство, скриншоты, заметки.
- **Вывод:** научился фиксировать условия среды (версия ОС, модель устройства) как часть данных для воспроизведения бага.
