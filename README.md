## Ключевые навыки
- Ручное тестирование (веб, мобильные приложения Android)
- Тестирование REST API (Postman)
- оформление баг‑репортов, работа с жизненным циклом бага, оценка Severity и Priority 
- Виды тестирования: smoke, regress, retest 
- Инструменты: DevTools, Android Studio 
- понимание HTTP, связи API и базы данных
- позитивное и негативное тестирование
- сбор и анализ логов через Logcat
- формирование отчетов по результатам тестирования
- составление чек листов, написание тест кейсов, приоритизация тестов
- сравнение ожидаемого и фактического результата, фиксация доказательств
- работа со статусами (Passed\Failed\Blocked)
- анализ требований и макетов
- декомпозиция требований, выявление серых зон
- применение техник тест дизайна: кэ, гз и оптимизация тестовых данных
- использование DevTools (Elements, Network, Console) для диагностики проблем на фронтенде
- проверка отображения интерфейса в разных браузерах и на разных разрешениях
