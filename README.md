## Ключевые навыки
- Ручное тестирование (веб, мобильные приложения Android)
- Тестирование REST API (Postman)
- оформление баг‑репортов, работа с жизненным циклом бага, оценка Severity и Priority 
- Виды тестирования: smoke, regress, retest 
- Инструменты: DevTools, Android Studio 
- понимание HTTP, связи API и базы данных
- позитивное и негативное тестирование
- сбор и анализ логов через Logcat
- формирование отчетов по результатам тестирования
- составление чек листов, написание тест кейсов, приоритизация тестов
- сравнение ожидаемого и фактического результата, фиксация доказательств
- работа со статусами (Passed\Failed\Blocked)
- анализ требований и макетов
- декомпозиция требований, выявление серых зон
- применение техник тест дизайна: кэ, гз и оптимизация тестовых данных
- использование DevTools (Elements, Network, Console) для диагностики проблем на фронтенде
- проверка отображения интерфейса в разных браузерах и на разных разрешениях

- https://docs.google.com/spreadsheets/d/1AKHlJFDRGXv9dGH_EEQ-ITX0FIzg1eIMCThmOjKEIuo/edit?usp=sharing 
- выполняла задачи по готовым тест-кейсам

- - находила баги и составляла баг-репорты по стандартной структуре (заголовок, шаги воспроизведения, фактический и ожидаемый результат, окружение, приоритет/серьёзность).
- **Инструменты:** браузер + Chrome DevTools (проверка консоли и вёрстки на разных разрешениях), скриншоты экрана для приложений к баг-репортам, тест-кейсы в таблице.

### 2. Тестирование сервиса Яндекс Маршруты - строит маршруты для транспорта разных видов, рассчитывает время и стоимость поездки. (Веб приложение).

- выполняла декомпозицию функциональности на отдельные проверяемые элементы
- составляла набор тест-кейсов на основе декомпозиции — позитивные и негативные проверки
- заводила баг-репорты по стандартной структуре
- **Инструменты:** таблица тест-кейсов (Google Sheets), мысленные карты для декомпозиции требований, браузер + Chrome DevTools, скриншоты для приложения к баг-репортам.

### 3. Тестирование сервиса Яндекс Метро - интерактивная карта метро с расчётом времени и прокладкой маршрутов. (Веб приложение, мобильная версия).
- https://docs.google.com/spreadsheets/d/1DB0HC-mmJW_snAEy7jurlD2U8WiHWSxN2piqcqWWM5I/edit?usp=sharing
- проводила проверки особенностей мобильного приложения: корректность отображения схемы, масштабирование, клики по станциям, построение маршрутов при разных состояниях сети
- работала с эмулятором в Android Studio: запускала приложение на разных виртуальных устройствах, проверяла поведение на разных версиях Android и разрешениях экрана
- выявляла расхождения между ожидаемым и фактическим поведением, заводила баг-репорты со скриншотами и условиями воспроизведения
- **Инструменты:** Android Studio (эмулятор, запуск и проверка мобильного приложения), браузер + Chrome DevTools (проверка адаптивности, сетевых запросов,эмуляция мобильных устройств), 
- научилась тестировать одну функциональность сразу в двух средах (веб и мобильное приложение) и подбирать подходящие инструменты под каждую: эмулятор для проверки поведения на разных устройствах, DevTools — для быстрой проверки адаптивности и сетевых ошибок. 

### 4. Тестирование функциональности в API Яндекс.Прилавка - координирует работу курьеров и складов. (Веб приложение).
- https://docs.google.com/spreadsheets/d/1Z2mGDGeoLhJm4zPJ41CLwvxjWu5gpw9HNIr0Ht9RDyg/edit?usp=sharing
- изучала документацию API (спецификации эндпоинтов, форматы запросов/ответов, коды состояний, обязательные и опциональные параметры)
- тестировала API через Postman: создавала запросы для разных методов (GET, POST и т. д.), проверяла коды ответов, валидность JSON, граничные и негативные сценарии
- выявляла несоответствия между ожидаемым поведением (по документации) и фактическим, заводила баг‑репорты с примерами запросов и ответов
- фиксировала условия воспроизведения: URL, метод, тело запроса, заголовки, ответ сервера, код ошибки
- **Инструменты:** Postman, документация API (Swagger, текстовые спецификации), браузер + DevTools
- научилась составлять отчет о проделанной работе, читать документацию API и переводить требования в тестовые сценарии, уверенно работать с Postman для тестирования REST API, а также фиксировать дефекты так, чтобы разработчик мог сразу воспроизвести проблему (включая полные примеры запросов и ответов). Закрепила понимание разницы между ошибкой на фронтенде и проблемой на бэкенде.

### 5. Дипломный проект: тестирование приложения Яндекс.Самокат - сервис кикшеринга. (Веб приложение, мобильная версия).
- https://docs.google.com/spreadsheets/d/1mRBGPJ6RqRiG58MjDe4wRiFbmwb-K05iZhZvUMN4O2o/edit?usp=sharing
- https://docs.google.com/spreadsheets/d/1X6cgcszFhgux5tg8w0q26Pw2WVEzfgx8E53UAAykFDs/edit?usp=sharing
- составляла чек‑лист по требованиям и проводила декомпозицию функциональности на атомарные проверяемые сценарии
- проводила проверки вёрстки по макетам (отступы, выравнивание, состояния кнопок, адаптивность на разных экранах)
- сверяла требования к бэкенду с документацией API, проверяя соответствие ожидаемых данных реальным ответам
- применяла техники тест‑дизайна: классы эквивалентности для группировки входных данных и анализ граничных значений для проверки крайних случаев

- **Инструменты:** DevTools, Charles, Postman, макеты (Figma), чек‑листы и таблицы (Google Sheets), скриншоты
- научилась переводить требования в структурированные проверки: разбивать функционал, применять техники КЭ и ГЗ, подбирать инструменты под тип задачи (DevTools для фронтенда, Charles для трафика, Postman для API).
